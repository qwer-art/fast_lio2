# Fast-LIO2 算法详细分析

## 符号说明

本文档使用以下数学符号：
- `a_meas`: 加速度计测量值
- `ω_meas`: 陀螺仪测量值
- `a_true`: 真实加速度
- `ω_true`: 真实角速度
- `b_a`: 加速度计偏差
- `b_g`: 陀螺仪偏差
- `n_a`: 加速度计测量噪声
- `n_g`: 陀螺仪测量噪声

## 命名规范

本文档遵循以下命名规范：

1. **旋转矩阵**: `R_XtoY` — 从坐标系 X 到坐标系 Y 的旋转
2. **四元数**: `q_XtoY` — 从坐标系 X 到坐标系 Y 的 JPL 四元数
3. **位置向量**: `p_XinY` — 坐标系 X 原点在坐标系 Y 中的坐标
4. **外参表示**: `T_LtoI` 表示从LiDAR到IMU的变换

### 代码变量与数学符号对应关系

| 代码变量 | 数学符号 | 含义 |
|---------|---------|------|
| `Lidar_R_wrt_IMU` | `R_LtoI` | LiDAR到IMU的旋转（配置参数） |
| `Lidar_T_wrt_IMU` | `p_LinI` | LiDAR在IMU中的位置（配置参数） |
| `offset_R_L_I` | `R_LtoI` | 状态中的外参旋转 |

| `state.pos` | `p_IinI0` | IMU在初始坐标系中的位置 |
| `state.rot` | `R_ItoI0` | IMU到初始坐标系的旋转 |
| `state.vel` | `v_IinI0` | IMU在初始坐标系中的速度 |
| `state.bg` | `b_g` | 陀螺仪偏差（IMU坐标系） |
| `state.ba` | `b_a` | 加速度计偏差（IMU坐标系） |

## 坐标系定义

- **I (IMU)**: IMU本体坐标系
- **L (LiDAR)**: 激光雷达坐标系
- **B (Base)**: 机器人基座坐标系（用于重力对齐，z轴通常向上）
- **I₀ (IMU初始坐标系)**: EKF状态估计的参考系，定义为IMU在 t=0 时刻的坐标系。初始化时 `R_ItoI0 = I`，之后 I₀ 固定不变。
- **W (世界坐标系)**: 重力对齐后的最终输出坐标系，z轴严格向上（与重力方向对齐）。

```
IMU测量 → EKF状态估计(I₀系) → 重力对齐 → 最终输出(W系)

R_ItoB = R_LtoB · R_ItoL = lidar_R_wrt_base_ · offset_R_L_I.inverse()
R_I0toW = R_BtoW · R_ItoB = R_gravity_aligned_ · R_ItoB

最终输出:
p_IinW = R_I0toW · p_IinI0
R_ItoW = R_I0toW · R_ItoI0
v_IinW = R_I0toW · v_IinI0
g_W = R_I0toW · g_I0
```

**重力向量**: `g_I0` 为I₀系下重力（EKF状态量），`g_W = [0, 0, -9.81]ᵀ` 为W系下重力。`R_gravity_aligned_` = `R_BtoW` 通过估计的 `g_I0` 和目标方向 `g_base_ = [0,0,-1]` 计算得到。

## 1. 标定参数

### 1.1 IMU-LiDAR 外参标定

**参数** (`spark_fast_lio.cpp:1288`):

```
extrinsic_T: [x, y, z]  → Lidar_T_wrt_IMU → p_LinI
extrinsic_R: [roll, pitch, yaw]  → Lidar_R_wrt_IMU → R_LtoI
```

**是否在线估计外参**:
- `extrinsic_est_en: true` → 外参作为状态量被EKF估计
- `extrinsic_est_en: false` → 外参固定为标定值

### 1.2 IMU 噪声参数

**参数**:

```
acc_cov:  σ_a²   加速度计测量噪声
gyr_cov:  σ_g²   陀螺仪测量噪声
b_acc_cov: σ_ba²  加速度计偏差随机游走噪声
b_gyr_cov: σ_bg²  陀螺仪偏差随机游走噪声
```

**IMU测量模型**:

加速度计测量的是**比力**(specific force)，即真实加速度减去重力加速度：

```
a_meas = R_ItoI0^T · (dv_IinI0/dt - g_I0) + b_a + n_a
ω_meas = ω_true + b_g + n_g
```

静止时 `dv/dt = 0`，`a_meas = -R_ItoI0^T · g_I0 + b_a + n_a`（测量重力的反方向）。

**偏差演化模型**:

```
db_g/dt = n_bg  (随机游走)
db_a/dt = n_ba  (随机游走)
```

**为什么 b_g, b_a, g 需要作为状态量？**

| 状态量 | 固定假设的问题 | 估计的作用 |
|-------|--------------|-----------|
| `b_g` | 偏差随时间漂移 | 在线校准消除角速度系统性误差 |
| `b_a` | 偏差随时间漂移 | 在线校准消除加速度系统性误差 |
| `g` | 初始姿态未知，无法假设方向 | 估计重力方向，支持任意姿态启动 |

## 2. 初始化

### 2.1 ESKF 状态向量

**状态定义** (`use-ikfom.hpp:12-14`):

```
x = [p_IinI0, R_ItoI0, R_LtoI, p_LinI, v_IinI0, b_g, b_a, g_I0]^T
     ────────  ────────  ──────  ──────  ────────  ───  ───  ────
       3维       3维      3维     3维      3维     3维  3维  2维(S²)
     ─────────────────────────────────────────────────────────────
                    流形: 23维 / 切空间: 24维
```

**维度说明**:

| 状态分量 | 流形维度 | 切空间维度 | 说明 |
|---------|---------|-----------|------|
| 位置 p | 3 | 3 | ℝ³ 欧氏空间 |
| 旋转 R | 3 (SO3) | 3 | SO(3)流形，切空间用旋转向量 |
| 外参旋转 R_L | 3 (SO3) | 3 | 同上 |
| 外参平移 p_L | 3 | 3 | ℝ³ 欧氏空间 |
| 速度 v | 3 | 3 | ℝ³ 欧氏空间 |
| 陀螺仪偏差 b_g | 3 | 3 | ℝ³ 欧氏空间 |
| 加速度计偏差 b_a | 3 | 3 | ℝ³ 欧氏空间 |
| 重力 g | 2 (S²) | 3 | S²流形，切空间嵌入 ℝ³ |
| **总计** | **23** | **24** | — |

**24 vs 23 差异来源**: `g ∈ S²` 的导数 `dg/dt` 在嵌入空间 ℝ³ 中用3维表示，但误差状态 `δg` 在切平面上只有2维。

### 2.2 IMU 初始化

**目标**: 在静止状态下估计重力方向、陀螺仪偏差和初始协方差

**条件**: 需要至少10帧IMU数据 (`imu_processing.hpp:154-209`)

**初始化步骤**:

1. **重力方向估计**: `g_I0 = -mean(a_meas) / ||mean(a_meas)|| · g_norm`

   静止时 `a_meas ≈ -g_I`，取反后得到重力方向。初始化时 `R_ItoI0 = I`，因此 `g_I0 = g_I`。

2. **陀螺仪偏差估计**: `b_g₀ = mean(ω_meas)`

   静止时 `ω_true = 0`，`ω_meas = b_g + n_g`，取平均抑制噪声。

3. **初始协方差矩阵** (`imu_processing.hpp:200-207`):

```
P₀ = diag(σ_p², σ_R², σ_R_L², σ_p_L², σ_v², σ_bg², σ_ba², σ_g²)
```

各分量初始不确定性由配置参数决定。

**EKF初始化标志** (`spark_fast_lio.cpp:1248`):

系统在 `INIT_TIME = 0.1` 秒后认为EKF已初始化。

## 3. 预测步 (Prediction Step)

### 3.1 整体框架

**核心方程**：

```
状态微分方程:    dx/dt = f(x, u, w)
状态积分:        x_{k+1} = x_k ⊞ f·dt
协方差传播:      P_{k+1} = F_k · P_k · F_kᵀ + G_k · Q_k · G_kᵀ
```

**张量维度**：

| 符号 | 维度 | 说明 |
|------|------|------|
| `x` | 流形23 / 切空间24 | 状态向量 |
| `δx` | 23 | 误差状态 |
| `u` | 6 | IMU测量输入 `[a_meas, ω_meas]ᵀ` |
| `w` | 12 | 过程噪声 `[n_g, n_a, n_bg, n_ba]ᵀ` |
| `f` | 24 | 状态微分 dx/dt（嵌入空间） |
| `f_x` | 24×23 | 原始雅可比 ∂f/∂δx（g列已映射到2维，g行仍为3维） |
| `f_w` | 24×12 | 原始噪声雅可比 ∂f/∂w（g行仍为3维） |
| `f_x_final` | 23×23 | 行映射+流形修正后的雅可比 |
| `f_w_final` | 23×12 | 行映射+流形修正后的噪声雅可比 |
| `F_x1` | 23×23 | 流形传播矩阵（对角块为Exp/A_matrix/Nx·Mx） |
| `F_k` | 23×23 | 离散状态转移矩阵 `F_x1 + f_x_final·dt` |
| `G_k` | 23×12 | 离散噪声雅可比 `f_w_final·dt` |

**变换链总览**：

```
状态雅可比:  f_x(24×23) ──Step1:ℝ³行恒等映射──→ f_x_final(23×23) ──Step4:离散化──→ F_k(23×23)
                           Step2:SO3行A_matrix修正        ↑
                           Step3:S²行Nx投影(3行→2行)      │
                                                          │
                            F_x1(23×23) ──对角块填充──────┘
                            F_k = F_x1 + f_x_final·dt

噪声雅可比:  f_w(24×12) ──Step1:ℝ³行恒等映射──→ f_w_final(23×12) ──Step4:离散化──→ G_k(23×12)
                           Step2:SO3行A_matrix修正
                           Step3:S²行Nx投影(3行→2行)
```

**状态微分方程** (`use-ikfom.hpp:36-47`):

```
dx/dt = f(x, u, w) ∈ ℝ²⁴

┌──────────────────────────────────────────────────────────────────┐
│ dp_IinI0/dt = v_IinI0                                          │ (位置)
│ dR_ItoI0/dt = R_ItoI0 · [ω]×                                   │ (旋转)
│ dR_LtoI/dt   = 0                                               │ (外参旋转)
│ dp_LinI/dt   = 0                                               │ (外参平移)
│ dv_IinI0/dt = R_ItoI0 · (a_meas - b_a - n_a) + g_I0            │ (速度)
│ db_g/dt      = n_bg                                            │ (陀螺仪偏差)
│ db_a/dt      = n_ba                                            │ (加速度计偏差)
│ dg_I0/dt     = 0                                               │ (重力)
└──────────────────────────────────────────────────────────────────┘

其中: ω = ω_meas - b_g - n_g, a = a_meas - b_a
```

### 3.1.1 S²流形与 Bx / Nx / Mx 矩阵

#### 空间、变量、维度定义

重力向量 `g` 模长固定为 9.81 m/s²，只有方向可变，位于球面 S² 上。围绕 S² 有三个空间，切空间有两种表示，Bx/Nx/Mx 是表示之间的转换：

| | 数学定义 | 符号 | 维度 | 约束 | 元素 | 含义 |
|---|---------|------|------|------|------|------|
| **S² 流形** | `{g ∈ ℝ³ : ‖g‖ = L}` | S²(L) | 2 | `‖g‖ = L` | `g` | 模长为 L 的向量集合 |
| **切空间 (2维坐标)** | `δ ∈ ℝ²` | ℝ² | 2 | 无 | `δ` | 切空间的参数化坐标，EKF 误差状态 |
| **切空间 (3维嵌入)** | `{v ∈ ℝ³ : gᵀv = 0}` | T_gS² ⊂ ℝ³ | 2 (嵌入3维) | `gᵀv = 0` | `v` | 切平面上实际的 3 维向量 |
| **嵌入空间** | `x ∈ ℝ³` | ℝ³ | 3 | 无 | `x` | S² 和 T_gS² 所在的母空间 |
| | | | | | | |
| **Bx** | `Bx = [e₁\|e₂]`, `gᵀe₁=0`, `gᵀe₂=0` → 具体构造见下方 | ℝ³ˣ² | — | — | — | 切平面的基：`δ ∈ ℝ² ↦ Bx·δ = v ∈ T_gS² ⊂ ℝ³` |
| **Mx** | `Mx = ∂(g⊞δ)/∂δ\|_{δ=0} = -[g]× · Bx` | ℝ³ˣ² | — | — | — | boxplus 雅可比：`δ ∈ ℝ² ↦ Mx·δ = Δg ∈ ℝ³` |
| **Nx** | `Nx = ∂(g'⊟g)/∂g'\|_{g'=g} = (1/‖g‖²) · Bxᵀ · [g]×` | ℝ²ˣ³ | — | — | — | boxminus 雅可比：`Δg ∈ ℝ³ ↦ Nx·Δg = δ ∈ ℝ²` |

三者关系：`Nx · Mx = I₂`（Nx 是 Mx 的左逆）。注意 `Nx · Bx ≠ I₂`，因为 Bx 是几何基而 Mx 包含运动学修正，二者相差 `-[g]×` 因子。

#### Bx: 切平面的基 ∈ ℝ³ˣ²

Bx 的两列是 T_gS² 上两个正交方向的 3 维嵌入表示：

```
Bx = [e₁ | e₂]    // e₁, e₂ ∈ ℝ³, gᵀe₁ = 0, gᵀe₂ = 0, 近似正交归一
```

切平面上任意 3 维向量 `v ∈ T_gS²` 都可表示为 `v = Bx · δ`，其中 `δ ∈ ℝ²` 是 2 维坐标。

构造方法 (`S2.hpp:165-200`, S2_typ=3):

当 `g` 不在南极（`g_z + L > 0`，L为球面半径）时:

```
         ┌ L - g_x²/(L+g_z)   -g_x·g_y/(L+g_z) ┐
Bx = 1/L │ -g_x·g_y/(L+g_z)    L - g_y²/(L+g_z) │
         ┝ -g_x                -g_y               ┠
         └                                         ┘
```

当 `g` 在南极附近时（退化情况）:

```
     ┌ 0   0 ┐
Bx = │ 0  -1 │
     └ 1   0 ┘
```

性质：`Bxᵀ · g = 0`，`Bxᵀ · Bx ≈ I₂`

#### Mx: boxplus 的雅可比 ∈ ℝ³ˣ²

S² 上的 boxplus 定义为旋转：

```
g_new = g ⊞ δ = Exp(Bx · δ) · g    // δ ∈ ℝ² → Bx·δ ∈ T_gS² ⊂ ℝ³ → Exp → 旋转g ∈ S²
```

Mx 是 boxplus 对 δ 的雅可比：

```
Mx = ∂(g ⊞ δ)/∂δ |_{δ=0} = -[g]× · Bx    // δ ∈ ℝ² ↦ Mx·δ ∈ ℝ³
```

`-[g]×` 的含义：`Bx · δ` 是切平面上的方向，`-[g]× · (Bx · δ)` 将其旋转 90° 到 g 的实际变化方向。**Bx 给出切平面方向，Mx 给出 g 沿该方向的实际变化**。

一般公式 (`‖δ‖ > 0`): `Mx = -Exp(Bx·δ) · [g]× · A(Bx·δ)ᵀ · Bx`，其中 `A` 是 SO3 左雅可比。

#### Nx: boxminus 的雅可比 ∈ ℝ²ˣ³

Nx 是 boxminus 的雅可比，将 ℝ³ 中的变化量投影回 ℝ² 切空间坐标：

```
Nx = ∂(g_new ⊟ g)/∂g_new |_{g_new=g} = (1/‖g‖²) · Bxᵀ · [g]×    // Δg ∈ ℝ³ ↦ Nx·Δg ∈ ℝ²
```

Nx 是 Mx 的左逆：`Nx · Mx = I₂`。即 Mx 把 ℝ² "展开"到 ℝ³，Nx 把 ℝ³ "折叠"回 ℝ²，二者互为逆操作。注意 `Nx · Bx ≠ I₂`，因为 Bx 和 Mx 语义不同（几何基 vs 运动学映射）。

#### 空间变换关系

```
  ℝ² (切空间坐标 δ)            ℝ³ (嵌入空间)
  ┌───────────────┐        ┌────────────────────┐
  │               │─ Bx ─→│ v = Bx·δ ∈ T_gS²   │  几何基：2维坐标→3维切向量
  │   δ ∈ ℝ²     │        │                    │
  │               │─ Mx ─→│ Δg = Mx·δ ∈ ℝ³     │  运动学：2维扰动→g的3维变化量
  │               │        │                    │
  │   δ ∈ ℝ²     │←─ Nx ─│ Δg ∈ ℝ³            │  投影：3维变化量→2维坐标
  └───────────────┘        └────────────────────┘
```

#### S² vs SO(3) 对比

S² 和 SO(3) 都是嵌入在高维空间中的低维流形，但切空间与嵌入空间的维度差不同，导致 S² 需要额外的 Bx/Nx/Mx 映射：

| 特性 | S² (重力方向) | SO(3) (旋转) |
|------|-------------|-------------|
| 名义状态 | `g ∈ ℝ³` (模长固定的向量) | `R ∈ ℝ³ˣ³` (正交矩阵) |
| 嵌入空间维度 | 3 | 9 |
| 真实自由度 (流形维度) | 2 | 3 |
| 切空间 | `T_gS² ⊂ ℝ³`, 2维 | `so(3) ≅ ℝ³`, 3维 |
| 误差状态 | `δ ∈ ℝ²` | `δθ ∈ ℝ³` (李代数 so(3)) |
| 切空间能否独立表示 | **不能**，必须嵌入在 ℝ³ 中 | **能**，so(3) ≅ ℝ³ 本身就是独立空间 |
| 升维工具 | `Mx ∈ ℝ³ˣ²`: `δ ∈ ℝ² ↦ Mx·δ ∈ ℝ³` | `[·]× ∈ ℝ³ˣ³`: `δθ ∈ ℝ³ ↦ [δθ]× ∈ ℝ³ˣ³` |
| 降维工具 | `Nx ∈ ℝ²ˣ³`: `v ∈ ℝ³ ↦ Nx·v ∈ ℝ²` | 不需要，so(3) 本身就是 3 维 |
| boxplus | `g ⊞ δ = Exp(Bx·δ) · g` ∈ S² | `R ⊞ δθ = R · Exp([δθ]×)` ∈ SO(3) |
| boxplus 含义 | δ ∈ T_gS²(ℝ²) → Bx·δ ∈ T_gS²(ℝ³) → Exp → 旋转g ∈ S² | δθ ∈ so(3)(ℝ³) → [δθ]× ∈ so(3)(ℝ³ˣ³) → Exp → 旋转R ∈ SO(3) |

关键区别：SO(3) 的切空间 so(3) 恰好是 3 维，与误差状态维度一致，`[·]×` 直接完成 ℝ³ ↔ so(3) 的映射。S² 的切空间是 2 维但嵌入在 3 维中，需要 Bx（升维）和 Nx（降维）在 ℝ² ↔ ℝ³ 之间转换。

#### 在 EKF 预测步中的作用

1. **行降维**：`f_x` 的 grav 行是 3 维（嵌入空间），用 Nx 投影到 2 维（切空间），使 24×23 → 23×23
2. **S² 传播修正**：`F_x1(grav块) = Nx · Exp(seg_S2) · Mx`，完成切空间上的协方差传播

详细的变换推导见 3.1.2（状态雅可比）和 3.1.3（噪声雅可比）。

### 3.1.2 状态雅可比矩阵 f_x 的完整变换推导

#### 起点：f_x ∈ ℝ²⁴ˣ²³（原始雅可比，嵌入空间行 + 切空间列）

`df_dx()` 返回 24×23。**列维度23**是因为g列已从3维映射到2维（通过Mx）；**行维度24**是因为g行仍为3维嵌入表示。

状态在嵌入空间中的行索引（dim）与切空间中的行索引（idx）对应关系：

| 状态分量 | dim（嵌入行） | idx（切空间行） | 行数 |
|---------|-------------|---------------|------|
| pos p | 0 | 0 | 3 |
| rot R | 3 | 3 | 3 |
| offset_R_L | 6 | 6 | 3 |
| offset_T_L | 9 | 9 | 3 |
| vel v | 12 | 12 | 3 |
| bg | 15 | 15 | 3 |
| ba | 18 | 18 | 3 |
| grav g | 21 | 21 | **2**（切空间） / **3**（嵌入空间） |

#### Step 2: SO3 流形修正（rot 和 offset_R_L）

**为什么需要修正？**

SO3 的误差状态传播方程为：

```
δθ_{k+1} = A(φ) · δθ_k + A(φ) · f_x(SO3行) · δx + A(φ) · f_w(SO3行) · w
```

其中 `φ = -ω·dt` 是旋转增量（负号因为误差状态定义），`A(φ)` 是 SO3 左雅可比矩阵。

**推导**：旋转的误差状态传播

1. 名义状态传播：`R_{k+1} = R_k · Exp(ω·dt)`
2. 真实状态传播：`R_{k+1}^{true} = R_k^{true} · Exp(ω_{true}·dt)`
3. 误差状态定义：`R^{true} = R · Exp(δθ)`
4. 代入得：`R_{k+1} · Exp(δθ_{k+1}) = R_k · Exp(δθ_k) · Exp(ω_{true}·dt)`
5. 利用 `Exp(a)·Exp(b) ≈ Exp(a+b+½[a]×b)` 和 `ω_{true} = ω - δθ_bg·dt - n_g·dt`（一阶近似）：
   ```
   δθ_{k+1} ≈ Exp(-ω·dt) · Exp(δθ_k) · Exp(ω·dt) · Exp(-δθ_bg·dt - n_g·dt)
            ≈ Exp(-ω·dt) · Exp(δθ_k + ω·dt - δθ_bg·dt - n_g·dt + ...)
   ```
6. 利用 BCH 公式展开，`Exp(φ)·Exp(δθ) ≈ Exp(φ + A(φ)·δθ)`：
   ```
   δθ_{k+1} ≈ A(-ω·dt) · δθ_k - A(-ω·dt) · δθ_bg·dt - A(-ω·dt) · n_g·dt
   ```

因此，f_x 的 SO3 行需要左乘 `A(φ)` 才能得到切空间中的正确雅可比。

**代码实现** (`esekfom.hpp:332-361`):

对每个 SO3 分量：
1. 计算 `seg_SO3 = -f_(dim+i)·dt`（即 `-ω·dt`）
2. `F_x1(idx:idx+2, idx:idx+2) = Exp(seg_SO3).toRotationMatrix()` — 旋转传播矩阵
3. `res_temp_SO3 = A_matrix(seg_SO3)` — 左雅可比
4. `f_x_final(idx:idx+2, i) = A(φ) · f_x_(dim:dim+2, i)` — 对每列左乘A
5. `f_w_final(idx:idx+2, i) = A(φ) · f_w_(dim:dim+2, i)` — 噪声行同样修正

**rot (idx=3, dim=3)**:
- `φ_R = -ω·dt`，`A_R = A(φ_R)`
- `F_x1(3:5, 3:5) = Exp(-ω·dt)` — 旋转传播
- `f_x_final(3:5, :) = A_R · f_x(3:5, :)`
  - 非零列只有 bg 列(15:17)：`f_x_final(3:5, 15:17) = A_R · (-I₃) = -A_R`
- `f_w_final(3:5, 0:2) = A_R · (-I₃) = -A_R`

**offset_R_L (idx=6, dim=6)**:
- `φ_RL = -f_(6:8)·dt = 0`（因 dR_L/dt = 0），`A_RL = A(0) = I₃`
- `F_x1(6:8, 6:8) = Exp(0) = I₃`
- `f_x_final(6:8, :) = I₃ · f_x(6:8, :) = f_x(6:8, :)` — 全零行，无实质修正
- `f_w_final(6:8, :) = I₃ · f_w(6:8, :) = f_w(6:8, :)` — 全零行

**A_matrix 公式** (`mtkmath.hpp:236-248`):

```
A(φ) = I₃ + (1-cos‖φ‖)/‖φ‖² · [φ]× + (‖φ‖-sin‖φ‖)/‖φ‖³ · [φ]×²

当 ‖φ‖ → 0 时: A(0) = I₃
```

#### Step 3: S² 流形修正（grav）

**为什么需要修正？**

S² 的误差状态在切空间中只有2维，但 f_x 的 grav 行有3行（嵌入空间）。需要：
1. **行降维**：将3行投影到2行（3维嵌入 → 2维切空间）
2. **流形传播修正**：S² 上的误差状态传播需要考虑切空间的曲率

**推导**：S² 误差状态的传播

1. 名义状态传播：`g_{k+1} = Exp(seg_S2) · g_k`，其中 `seg_S2 = (dg/dt)·dt`
2. 误差状态定义：`g^{true} = g ⊞ δg = Exp(Bx·δg) · g`
3. 误差状态传播：
   ```
   g_{k+1} ⊞ δg_{k+1} = Exp(Bx_k·δg_k) · g_k
   Exp(Bx_{k+1}·δg_{k+1}) · g_{k+1} = Exp(Bx_k·δg_k) · g_k
   ```
4. 利用 `g_{k+1} = Exp(seg_S2) · g_k`：
   ```
   Exp(Bx_{k+1}·δg_{k+1}) · Exp(seg_S2) · g_k = Exp(Bx_k·δg_k) · g_k
   ```
5. 两边右乘 `g_k` 的 boxminus 雅可比 Nx（投影到切空间）：
   ```
   δg_{k+1} = Nx · Exp(seg_S2) · Mx · δg_k + res_temp_S2 · f_x(grav行) · δx + res_temp_S2 · f_w(grav行) · w
   ```
   其中 `res_temp_S2 = -Nx · Exp(seg_S2) · [g]× · A(seg_S2)ᵀ`

**代码实现** (`esekfom.hpp:363-402`):

1. `seg_S2 = f_(dim+i)·dt`（对grav，`f_(21:23) = 0`，所以 `seg_S2 = 0`）
2. `Exp(seg_S2) = Exp(0) = I₃`
3. `Nx = S2_Nx_yy(idx)` — 当前g处的Nx矩阵
4. `Mx = x_before.S2_Mx(vec, idx)` — 零扰动处的Mx矩阵
5. `F_x1(21:22, 21:22) = Nx · Exp(seg_S2) · Mx`
6. `x_before_hat = [g]×`（S2_hat）
7. `res_temp_S2 = -Nx · Exp(seg_S2) · [g]× · A(seg_S2)ᵀ`
8. `f_x_final(21:22, i) = res_temp_S2 · f_x_(21:23, i)` — 3行→2行
9. `f_w_final(21:22, i) = res_temp_S2 · f_w_(21:23, i)` — 3行→2行

**Fast-LIO 简化**（因 dg/dt = 0）：

| 矩阵 | 一般形式 | Fast-LIO简化（seg_S2=0） |
|------|---------|------------------------|
| `Exp(seg_S2)` | `Exp(seg_S2)` | `I₃` |
| `A(seg_S2)` | `A(seg_S2)` | `I₃` |
| `F_x1(grav块)` | `Nx · Exp(seg_S2) · Mx` | `Nx · I₃ · Mx = Nx · Mx = I₂` |
| `res_temp_S2` | `-Nx · Exp(seg_S2) · [g]× · A(seg_S2)ᵀ` | `-Nx · [g]×` |
| `f_x_final(grav行)` | `res_temp_S2 · f_x_(grav行)` | `(-Nx·[g]×) · O₃ₓ₂₃ = O₂ₓ₂₃` |
| `f_w_final(grav行)` | `res_temp_S2 · f_w_(grav行)` | `(-Nx·[g]×) · O₃ₓ₁₂ = O₂ₓ₁₂` |

**为什么 Nx·Mx = I₂？**

因为 Nx 是 Mx 的左逆。Mx 将 ℝ² 切空间坐标映射到 ℝ³ 嵌入空间的变化量，Nx 将 ℝ³ 变化量投影回 ℝ² 切空间坐标。二者互为逆操作。

**为什么 f_x_final 的 grav 行全零？**

因为 f_x 的 grav 行(21:23) 本身全零（dg/dt = 0），所以无论 res_temp_S2 是什么，乘积都是零。


```
F_k = F_x1 + f_x_final · dt
```

其中 `F_x1` 已经包含了流形上的指数映射传播（Exp），`f_x_final·dt` 是连续雅可比的离散化修正。

### 3.2 预测步伪代码

**调用位置**: `imu_processing.hpp:237` → `esekfom.hpp:predict`

```cpp
void predict(state& x, matrix& P, input u, double dt, matrix Q) {

    // Step 1: 计算状态微分 f = dx/dt
    f = compute_f(x, u);

    // Step 2: 状态积分（流形上的积分）
    // x_{k+1} = x_k ⊞ f·dt
    x_new = manifold_integration(x, f, dt);
    //   - 位置:   p_new = p + v·dt
    //   - 旋转:   R_new = R · Exp(ω·dt)     // 指数映射
    //   - 速度:   v_new = v + (R·(a-ba) + g)·dt
    //   - 其他:   不变

    // Step 3: 计算雅可比矩阵
    f_x = compute_F(x, u);   // ∂f/∂x, 24×23（已含S²列映射）
    f_w = compute_G(x);       // ∂f/∂w, 24×12

    // Step 4: 行映射 + 流形修正（见3.1雅可比处理流程）
    // ℝ³行恒等映射, SO3行用A_matrix修正, S²行用Nx/Mx投影
    // f_x(24×23) → f_x_final(23×23)
    // f_w(24×12) → f_w_final(23×12)
    // 同时构建 F_x1(23×23): 对角块为流形传播矩阵

    // Step 5: 离散化
    F_k = F_x1 + f_x_final * dt;

    // Step 6: 协方差传播
    P_new = F_k * P * F_k.transpose()
          + (dt * f_w_final) * Q * (dt * f_w_final).transpose();

    x = x_new;
    P = P_new;
}
```

**实现细节**：

| 步骤 | 注意事项 |
|------|----------|
| Step 1 | 需要去偏差：`ω = ω_meas - b_g`, `a = a_meas - b_a` |
| Step 2 | SO(3)用`Exp()`，S²用切空间投影，ℝⁿ用普通加法 |
| Step 4 | SO3修正用`A_matrix`，S²修正用`Nx/Mx`投影(3行→2行) |
| Step 6 | 保证对称性：`P = (P + Pᵀ)/2` |

## 4. 更新步 (Update Step)

### 4.1 测量方程

**公式** (`spark_fast_lio.cpp:518-627`):

```
h(x) = nᵀ · p_I0 + d

其中:
p_I0 = R_ItoI0 · (R_LtoI · p_L + p_LinI) + p_IinI0
```

**物理意义**: 点 `p_I0` 到平面 `π: nᵀ·p + d = 0` 的距离，点在平面上时 `h(x) = 0`。

### 4.2 测量雅可比矩阵

```
H = ∂h/∂x = nᵀ · ∂p_I0/∂x

∂p_I0/∂p_IinI0 = I₃
∂p_I0/∂R_ItoI0 = -R_ItoI0 · [p_I]×
∂p_I0/∂R_LtoI = R_ItoI0 · [p_L]× · R_LtoI (如果估计外参)
∂p_I0/∂p_LinI = R_ItoI0                   (如果估计外参)

其中 p_I = R_LtoI · p_L + p_LinI

H = nᵀ · [I₃,  -R·[p_I]×,  R·[p_L]×·R_LtoI,  R,  0, 0, 0, 0]
```

### 4.3 迭代卡尔曼更新伪代码

**算法**: IEKF (`esekfom.hpp:1655-1979`)

```cpp
void update_iterated(state& x, matrix& P, Measurement z, Matrix R) {
    x_propagated = x;  // 保存预测值（用于回退）
    P_propagated = P;
    dx = 0;            // 误差状态

    for (int iter = 0; iter < maximum_iter; iter++) {
        // Step 1: 计算测量残差和雅可比
        for (each point i) {
            p_I0 = transform_point_to_I0(x, p_L);
            h_i = n_iᵀ · p_I0 + d_i;
            H_i = compute_H(x, p_L, n_i);
        }

        // Step 2: 计算卡尔曼增益
        if (n > m) {
            K = P · Hᵀ · (H · P · Hᵀ / R + I_m)⁻¹ / R;
        } else {
            K = (Hᵀ · H + P / R)⁻¹ · Hᵀ;
        }

        // Step 3: 更新误差状态（IEKF迭代公式）
        dx_new = dx - K · h(x) - (K · H - I) · dx;

        // Step 4: 流形上的状态更新
        x = x ⊞ dx_new;

        // Step 5: 收敛判断
        if (||K · h(x)||_∞ < ε) break;
        dx = dx_new;
    }

    // Step 6: 协方差更新
    P = (I - K · H) · P;
}
```
